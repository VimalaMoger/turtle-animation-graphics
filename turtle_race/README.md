Turtle Race:

random_color() - Returns the list of basic colors

make_turtle_move() - This positions each turtle at the start line

start_turtle_race() - Each turtle moves a random distance each turn until one crosses the finish line

User bet: Ask the player to choose a turtle color before the race

The turtles will race, and the program will announce the winner.

Approach -  loops, random numbers, turtle graphics, and event handling
